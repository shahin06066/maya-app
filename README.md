# Maya — Your money, made simple

A mobile-first, Maya-inspired money app frontend built with React, Vite and Tailwind CSS. It includes an interactive wallet, QR payments, bill payments, mobile load, card controls and savings goals.

## Live preview

https://shahin06066.github.io/maya-app/

## Features

- Live wallet and savings balances
- Send money to existing contacts or a new recipient
- Cash in, bill payments, mobile load and simulated QR Ph payments
- Maya debit card with reveal details, freeze and payment controls
- Savings goals, contributions and interest estimator
- Full transaction activity with search and filters
- Profile, security preferences, statements and support sheets
- Responsive native-app shell with a desktop presentation stage

All balances, goals and activity update live across the app. Data is stored in memory and resets when the page reloads.

## Tech stack

- React 19
- TypeScript
- Vite 7
- Tailwind CSS 4
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The deployment build is committed to `docs/` and served with GitHub Pages.
